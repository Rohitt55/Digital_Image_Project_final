# PixelLab BAUST report

The report follows the supplied BAUST template. Edit main.tex metadata before submission. Supervisor, designation, examination, signatures and submission date remain unconfirmed. Only the candidate name and ID credited in the app are populated.

Compile in this directory with pdflatex main.tex, then repeat pdflatex twice to resolve contents and cross references. References are embedded in BackMatter/references.tex and do not require BibTeX. The PDF delivered beside this source was typeset separately with the same content, A4 margins, Times typography and chapter structure because no TeX compiler is installed locally. LaTeX pagination may differ. The original template remains unchanged in the project root.
