# PixelLab — সম্পূর্ণ Offline Android App

১. `PixelLab-offline.apk` ফোনে কপি করে ইনস্টল করুন। প্রয়োজন হলে APK খোলার app-কে install করার অনুমতি দিন।
২. PixelLab খুলুন। প্রথমবার Python engine চালু হতে একটু সময় লাগতে পারে। কোনো download লাগবে না।
৩. **Choose photo** অথবা **Use sample image** চাপুন। Operation বেছে **Run operation** চাপুন।
   উপরের **☰** menu খুলে sidebar-এর **CHAPTER** থেকে chapter ১–৮ বাছাই করুন। Search সেই chapter-এর মধ্যে কাজ করবে। Operation-এর নামে চাপলে sidebar বন্ধ হয়ে তার settings দেখাবে। **Clear filters** চাপলে সব operation ফিরে আসবে।
৪. Result, figure/table ও console output দেখুন। ছবিতে চাপলে zoom এবং Save button দিয়ে ফোনে রাখা যায়।

কম্পিউটার, server, Wi-Fi বা mobile data লাগবে না। App-এ Internet permission নেই। ৫৯টি operation ও Python example APK-র ভেতরেই আছে।

Android 7.0 বা পরের version এবং 64-bit ARM phone প্রয়োজন। আগের PixelLab-এর ওপর update করা যাবে। ছবি সর্বোচ্চ ১২ megapixel।
